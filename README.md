# Full Stack Open

My solutions to the exercises from the [Full Stack Open](https://fullstackopen.com/en/) course offered by the University of Helsinki.

## About the Course

Full Stack Open focuses on modern web development using JavaScript. The course covers React, Node.js, Express, GraphQL, TypeScript, React Native, CI/CD, containers, databases, and more.
